Breadth-first search, step by step

Breadth-first search visits a graph in rings: first the start node, then all nodes one edge away, then two edges away, and so on. A queue keeps that order.

Click the figure, then use ← →, space, Home and End, or the buttons.

How it works

  1. Put the start node in the queue and mark it visited.
  2. Take the node at the front of the queue.
  3. For each neighbor not yet visited: mark it visited, mark the edge, and add it to the back of the queue.
  4. Repeat until the queue is empty.

Cost

Time
O(V + E): every node and edge is looked at once.
Space
O(V) for the queue and the visited set.
Finds
Shortest paths, by edge count, in unweighted graphs.
