Depth-first search, step by step

Depth-first search follows one path as deep as it can, then backs up to the last node with an unvisited neighbor. This version is recursive; the figure draws its call stack.

Click the figure, then use ← →, space, Home and End, or the buttons.

How it works

  1. Visit the start node.
  2. Go to its first unvisited neighbor and visit it the same way.
  3. When a node has no unvisited neighbors, return to the node that called it.
  4. Done when the first call returns.

Cost

Time
O(V + E).
Space
O(V) for the visited set and the call stack.
Used for
Cycle checks, topological order, connected parts, mazes.
