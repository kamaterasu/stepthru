stepthru

Trace the real code. Step through what it does.

Write the real algorithm, call tracer hooks inside it, and get a figure readers can play, pause and scrub, with a caption for every step. No dependencies, accessible by keyboard and screen reader.

GitHub · npm · Changelog · MIT · Test coverage

npm install stepthru

Examples

Click a figure, then use ← →, space, Home and End, or the buttons. Each figure's full source is under it.
