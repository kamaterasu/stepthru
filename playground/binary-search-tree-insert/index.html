Binary search tree insert, step by step

In a binary search tree every node's left subtree holds smaller values and its right subtree holds the rest. To insert, walk down from the root, going left or right after each compare, until you reach an empty spot.

Click the figure, then use ← →, space, Home and End, or the buttons.

How it works

  1. If the tree is empty, the value becomes the root.
  2. Compare the value with the current node. Smaller goes left, equal or larger goes right.
  3. If that child is empty, add the value there.
  4. Otherwise move to that child and compare again.

Cost

Time
O(h) per insert, where h is the tree height: O(log n) when balanced, O(n) for sorted input.
Space
O(1) extra for this loop version.
Note
Inserting sorted values makes a tree that is a single long path.
